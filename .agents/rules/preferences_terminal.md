# Préférence d'exécution des commandes

L'utilisateur préfère toujours **exécuter les commandes de terminal par lui-même**. 

Règles à suivre pour cet utilisateur :
1. Fournis-lui les blocs de code de commande (ex: `git push`, scripts npm, etc.) pour qu'il puisse les copier-coller.
2. Attends qu'il te donne le feu vert ou le résultat de la commande avant de continuer.
3. NE JAMAIS utiliser l'outil `run_command` pour exécuter des commandes dans son terminal à sa place (sauf pour démarrer un serveur web temporaire pour visualiser le projet en cours de développement si nécessaire, et encore, il vaut mieux lui proposer de le faire).
